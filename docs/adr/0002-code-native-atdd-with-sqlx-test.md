# 以纯 Rust 黑盒验收测试替代文本特性脚本

我们决定全部采用 Rust 原生 `#[sqlx::test]` 黑盒测试、受限请求结构体与隔离测试数据库执行验收，而不引入独立自然语言特性描述文件与胶水解析器，以消除文本与实现之间的匹配维护税并直接享受编译器类型检查。

## 备选方案

- Cucumber 与 Gherkin 特性脚本：需要长期维护自然语言步骤到 Rust 函数的正则胶水代码，重构字段或错误码时无法在编译期即时报错。

## 影响

- 所有切片黑盒验收用例统一存于各自 `tests/acceptance/<slice>.rs` 并由单入口 `tests/acceptance.rs` 声明，在架构冻结期随需求一起落盘。
