# 并发工作树保留独立构建目录并共享 sccache 缓存

我们决定让每个并发工作树各自维护独立的 `target` 输出目录，并在工作区配置统一设置编译缓存包装器 `sccache`，而不共享同一个全局 `CARGO_TARGET_DIR`，以消除多代理并发运行检查时的文件锁互斥阻塞。

## 备选方案

- 多个工作树共享同一 `CARGO_TARGET_DIR`：Cargo 对目标目录持有全局互斥锁，并发执行静态检查与测试会退化为串行等待并频繁冲刷彼此缓存。

## 影响

- 各开发沙盒会占用少量本地切片产物磁盘空间，但所有公共第三方依赖在命中 `sccache` 后均无需重复编译。
