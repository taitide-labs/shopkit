# 采用 VSA、DMMF 与 CQRS 融合分层架构

我们决定在工作区外层按限界上下文与垂直切片目录组织功能，在共享领域核及写切片内部采用纯函数核心加命令式外壳分层，并以读写前缀区分命令与查询路径，从而同时获得多代理并发无冲突合并与强类型领域不变量保障。

## 备选方案

- 纯正 DMMF 技术壳结构：集中式路由、DTO 与持久化层会导致多个 AI 并行新增功能时同时争抢修改同一组文件。
- 无共享领域核的纯正 VSA：多个用例各自操作同一聚合状态，容易产生订单状态流转漂移与重复计价逻辑。

## 影响

- 读切片直接查询数据库视图投影并省略领域核与 `workflow.rs`；只有存在复杂计算或不变量的写切片才拆分 `workflow.rs` 或调用共享 `domain` 层。
