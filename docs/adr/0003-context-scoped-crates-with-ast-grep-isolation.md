# 按限界上下文划分 Crate 并在包内以静态规则隔离切片

我们决定为每个限界上下文建立共享 `domain` 包与统一 `slices` 包，由静态规则禁止切片间互相导入，而不为每个独立用例创建一个独立 Cargo Crate，从而在保持包级并发与依赖清白的同时避免工作区二进制链接膨胀。

## 备选方案

- 一切片一独立 Cargo Crate：虽然依赖编译器即可隔绝跨切片导入，但数十个独立测试二进制重复链接异步运行时与数据库驱动会大幅拖慢本地迭代与持续集成。

## 影响

- 同上下文内严禁出现切片之间的 `use` 导入，由 `rules/no-cross-slice-imports.yml` 与 `rules/no-domain-in-query.yml` 在毫秒级扫描拦截。
